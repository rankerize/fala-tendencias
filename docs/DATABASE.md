## 2. Definición del Esquema (DDL)

La tabla principal de almacenamiento es `tendencias_queries`:

```sql
CREATE TABLE IF NOT EXISTS public.tendencias_queries (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    query TEXT NOT NULL,
    search_interest INTEGER DEFAULT 0,
    increase_percent TEXT,
    is_breakout BOOLEAN DEFAULT FALSE,
    tipo_busqueda VARCHAR(20) DEFAULT 'top', -- 'top' o 'rising'
    f1_codigo VARCHAR(10),                   -- Ej. 'F00', 'F19', 'F18'
    f2_codigo VARCHAR(10),                   -- Ej. 'F0001', 'F1901'
    carpeta_origen VARCHAR(100),             -- Ej. 'celulares', 'tenis'
    archivo_origen VARCHAR(255),             -- Nombre del archivo CSV/JSON fuente
    extracted_at TIMESTAMPTZ DEFAULT NOW(),
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### Índices de Rendimiento Recomendados

Dado que el dashboard realiza consultas paginadas con `.range(from, from + limit - 1)` y filtros en memoria o directos:

```sql
-- Índice para filtros jerárquicos de categoría
CREATE INDEX IF NOT EXISTS idx_tendencias_f1_f2 ON public.tendencias_queries(f1_codigo, f2_codigo);

-- Índice para términos con crecimiento explosivo (Breakouts)
CREATE INDEX IF NOT EXISTS idx_tendencias_breakout ON public.tendencias_queries(is_breakout) WHERE is_breakout = TRUE;

-- Índice para ordenamiento por volumen
CREATE INDEX IF NOT EXISTS idx_tendencias_interest ON public.tendencias_queries(search_interest DESC);

-- Índice para búsqueda de texto completo en queries
CREATE INDEX IF NOT EXISTS idx_tendencias_query_trgm ON public.tendencias_queries USING gin (query gin_trgm_ops);
```

## 3. Diccionario de Datos

| Columna | Tipo | Nulo | Descripción y Ejemplos |
| :--- | :--- | :--- | :--- |
| `id` | `BIGINT` | NO | Identificador secuencial único. |
| `query` | `TEXT` | NO | Cadena de búsqueda ingresada por los usuarios en Google Colombia (ej. *"iphone 16 pro max"*, *"tenis adidas samba"*). |
| `search_interest` | `INTEGER` | SÍ | Métrica normalizada de 0 a 100 representativa del volumen relativo de búsqueda. |
| `increase_percent` | `TEXT` | SÍ | Porcentaje de incremento reportado en Google Trends (ej. *"+450%"*, *"+1,200%"*). Para crecimientos masivos se acompaña con `is_breakout = true`. |
| `is_breakout` | `BOOLEAN` | NO | Indica si el término superó un umbral de crecimiento explosivo repentino (+5000%). |
| `tipo_busqueda` | `VARCHAR(20)` | SÍ | Distingue entre búsquedas consolidadas (`top`) y búsquedas emergentes (`rising`). |
| `f1_codigo` | `VARCHAR(10)` | SÍ | Código corporativo Falabella de Nivel 1 (`F00`, `F19`, `F18`, `F13`, `F43`, `F14`, `F35`, `F06`). |
| `f2_codigo` | `VARCHAR(10)` | SÍ | Código corporativo Falabella de Nivel 2 (`F0001`, `F1901`, `F1902`, `F1903`, etc.). |
| `carpeta_origen` | `VARCHAR(100)`| SÍ | Categoría interna o carpeta de extracción (ej. *"audio"*, *"calzado"*, *"smartphones"*). |
| `archivo_origen` | `VARCHAR(255)`| SÍ | Nombre del dataset o CSV de ingesta para auditoría de datos. |
| `extracted_at` | `TIMESTAMPTZ` | SÍ | Fecha de corte temporal de las búsquedas analizadas. |

## 5. Procedimiento para Ingestar Nuevos Datos

Para agregar nuevas extracciones de Google Trends a Supabase:

### Opción A: Vía Python Script (Recomendado)
```python
import os
import pandas as pd
from supabase import create_client

SUPABASE_URL = "https://ybfbccrdscgpeujymggu.supabase.co"
SUPABASE_SERVICE_ROLE_KEY = os.getenv("SUPABASE_SERVICE_ROLE_KEY") # Usar service_role para escritura masiva

supabase = create_client(SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY)

df = pd.read_csv("nuevas_tendencias_diciembre.csv")

# Formatear columnas al esquema esperado
records = df.to_dict(orient="records")

# Inserción en batches de 500 para evitar timeouts
batch_size = 500
for i in range(0, len(records), batch_size):
    batch = records[i:i + batch_size]
    res = supabase.table("tendencias_queries").insert(batch).execute()
    print(f"Insertados {i + len(batch)}/{len(records)}")
```

### Opción B: Importación Directa desde el Dashboard de Supabase
1. Ingresar a [app.supabase.com](https://app.supabase.com/) y seleccionar el proyecto `fala-tendencias` (`ybfbccrdscgpeujymggu`).
2. Ir a **Table Editor** > `tendencias_queries`.
3. Seleccionar **Insert** > **Import data from CSV**.
4. Mapear las columnas con el archivo CSV a importar.

## 6. Consultas SQL Frecuentes para Validación

```sql
-- Total de registros cargados por categoría F1
SELECT f1_codigo, COUNT(*) as total_terminos
FROM public.tendencias_queries
GROUP BY f1_codigo
ORDER BY total_terminos DESC;

-- Términos con mayor volumen en Black Friday
SELECT query, search_interest, increase_percent, is_breakout
FROM public.tendencias_queries
WHERE f1_codigo = 'F00'
ORDER BY search_interest DESC
LIMIT 20;

-- Top 15 Breakouts emergentes en Tecnología
SELECT query, increase_percent, carpeta_origen
FROM public.tendencias_queries
WHERE f1_codigo = 'F19' AND is_breakout = TRUE
ORDER BY id DESC
LIMIT 15;
```
